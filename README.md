# 我的日常

仅供个人在本机浏览器使用的工作与生活管理 App。页面资源和记录都留在本机，不需要账号或远程服务。

## 启动

1. 安装 Node.js 20 或更新版本。
2. 在本目录运行：

   ```powershell
   node server.mjs
   ```

3. 在电脑浏览器打开 <http://127.0.0.1:4173>。

保持本地服务运行时即可使用。需要继续查看原有数据时，请使用相同浏览器配置和地址；浏览器站点数据与本地服务地址关联。清除浏览器站点数据可能删除记录，请先从“数据与设置”导出备份。

## 测试

在本目录运行：

```powershell
node --test test/*.test.mjs
```

测试使用 Node 自带测试框架，无需安装 npm 依赖。测试覆盖数据校验、表单默认值、日期筛选、首页摘要、持久化接口、备份编解码和本地 HTTP 服务。

## 页面与数据

- `index.html`：应用入口。
- `src/app.mjs`：页面渲染和交互。
- `src/domain.mjs`：数据集合、记录校验和备份格式。
- `src/storage.mjs`：IndexedDB 本地持久化、级联删除和整份恢复。
- `src/selectors.mjs`：首页摘要、今日待办和备忘查询。
- `src/services.mjs`：启动和数据恢复后的必要默认数据处理。
- `src/styles.css`：本地界面样式。
- `server.mjs`：只监听 `127.0.0.1` 的静态文件服务。
- `PRD.md`：产品需求和验收标准。

备份文件是带格式版本的 JSON。导入前会校验文件；确认导入后，备份中的全部数据会替换当前数据，不会自动合并。
